# Project: Aesthetic Match

## Purpose

To build a standalone web application that remembers and creates PERSISTENT fashion aesthetic recommendation from 5-10 fashion influencers (via image upload), matches it against a live multi-brand catalog from real Shopify stores, and returns explainable, ranked product recommendations instead of "one-time image upload similar products recommendation".

This is positioned as a concept for the "Shop App" (Shopify's aggregated order tracking platform) feature.

## Target User

A woman who shops online and wants curated recommendations pulled from multiple independent brands that suit her personal aesthetic/style archetype, rather than browsing one store at a time. This should inform product, catalog, and UI decisions in every remaining phase -- e.g., don't add men's/unisex brands back into the seed list without revisiting this, and copy/imagery choices in the UI phase should speak to this user specifically.
